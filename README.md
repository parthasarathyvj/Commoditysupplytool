# CST Commodity Supply Tool

React and Vite implementation of the Commodity Supply Tool dashboard.

## Local development

```bash
npm install
npm run dev
```

Demo users: `admin / cst@123` and `tiger / tiger@123`.

## Build

```bash
npm run build
npm run preview
```

The production bundle is published at the root of the `gh-pages` branch for GitHub Pages. The Vite base path is `/Commoditysupplytool/`.
