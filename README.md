# CST Commodity Supply Tool

React and Vite implementation of the Commodity Supply Tool dashboard.

## Local development

```bash
npm install
npm run dev
```

Demo users: `admin / cst@123` and `tiger / tiger@123`.

## Build

```bash
npm run build
npm run preview
```

GitHub Pages deployment is configured in `.github/workflows/deploy.yml` and publishes pushes to `gh-pages`. The Vite base path is `/Commoditysupplytool/`.
